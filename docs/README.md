# مستندات

یادداشت‌های فنی درباره‌ی ساختن و نگه‌داشتن یک زیرساخت شخصی. هر صفحه از روی یک راه‌اندازی واقعی نوشته شده است — با نسخه‌های مشخص، خطاهایی که واقعاً پیش آمدند و راه‌حلی که در عمل جواب داد.

---

**[راه‌اندازی سرور خانگی](/home-server.md)**

تبدیل یک لپ‌تاپ Sony Vaio به سرور شخصی: نصب Ubuntu Server، پیکربندی شبکه با netplan، جلوگیری از خوابیدن با بستن درب، سخت‌سازی SSH و fail2ban، سپس Docker، Dokploy، Cloudflare Tunnel و Tailscale.

بخش عیب‌یابی هم هست: فلشی که بوت نمی‌شود، قطعی مکرر وای‌فای، خطای احراز هویت دیتابیس Dokploy، بالا نیامدن cloudflared، خطاهای DNS و برچسب `Invalid` روی دامنه.

**[افزودن مستند جدید](/contributing.md)**

قواعد نام‌گذاری فایل، ساختار سایدبار، سبک نوشتن، لینک بین صفحه‌ها، تست محلی پیش از push و نکته‌های امنیتی.

---

> 💡 برای پیدا کردن یک موضوع در همه‌ی صفحه‌ها، از کادر جست‌وجوی بالای سایدبار استفاده کن.

> ⚠️ این سایت داخل tailnet منتشر شده و **همه‌ی اعضای tailnet به آن دسترسی دارند**. رمز عبور، توکن، کلید API و محتوای فایل‌های محیطی را داخل مستندات ننویس.
